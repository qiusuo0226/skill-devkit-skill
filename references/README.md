| `01-init.md` | 空文件夹 / 空仓 / 半套初始化 |
| `02-adopt.md` | 已有技能、无规范时收编；半套收编恢复 |
| `03-skill-roots.md` | 助手技能目录探测（占用、收编闸、试用拷贝） |
| `04-triggers.md` | 同义开口全表（不进 description） |
