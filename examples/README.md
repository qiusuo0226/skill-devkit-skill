# 使用示例

看怎么开口、助手问什么、你怎么回、文件夹里会多出什么。

人名和 Skill 名是假的，问法是真的。贯穿始终：林夏要做一个「会议速记」技能——把会议纪要收成决议和行动项。

```mermaid
flowchart LR
    A["空文件夹"] --> B["说：初始化 skill"]
    B --> C["问完、你点头"]
    C --> D["文件夹里有了这个技能"]
    D --> E["以后不必再打开本包"]
```

```mermaid
flowchart LR
    F["工作区换成那个技能的文件夹"] --> G["写规则 / 升级 / 打包 / 试用"]
    G --> H["先列方案，你说同意执行"]
    H --> I["改文件、打安装包"]
```

建议先看 01，卡住了再看 03～05、07。建好之后：写规则看 10，升级看 08，打包看 06，试用看 16。

## 初始化

| 文件 | 看什么 | 你开口可以这样说 |
|---|---|---|
| [01-初始化空文件夹.md](01-初始化空文件夹.md) | 从头问到建好 | 「初始化 skill」 |
| [02-一句话带齐信息.md](02-一句话带齐信息.md) | 开头说全了，就不再问 | 「开发一个 skill，英文名 meeting-notes，把纪要收成行动项」 |
| [03-已经初始化过.md](03-已经初始化过.md) | 建过了不能再初始化 | 「再初始化一下」 |
| [04-文件夹里已有东西.md](04-文件夹里已有东西.md) | 非空目录会停 | 「把这个文件夹初始化成 skill」 |
| [05-英文名不合格.md](05-英文名不合格.md) | 中文不能当英文名 | 「就叫会议速记」 |
| [07-英文名已经有人用.md](07-英文名已经有人用.md) | 助手里已有同名技能 | 英文名先说 `pdf` |

## 初始化之后

工作区换成**那个技能的文件夹**。不要再对本包说。改技能正文前先列方案，你回复「同意执行」才动手。

| 文件 | 看什么 | 你开口可以这样说 |
|---|---|---|
| [08-初始化之后怎么升级.md](08-初始化之后怎么升级.md) | 怎么触发升级；不必报版本号 | 「升级这个 skill。给它加一个能力：……」 |
| [09-对本包说升级会停.md](09-对本包说升级会停.md) | 对本包说升级会停 | （先换文件夹，再按 08 说） |
| [10-初始化之后写规则.md](10-初始化之后写规则.md) | 空架子里写入真正要做的事 | 「把技能真正要做的规则写进去」 |
| [11-初始化之后直接改会先出方案.md](11-初始化之后直接改会先出方案.md) | 说「直接改吧」也先出方案 | 「技能正文加上：没有决议就明说没有」 |
| [12-初始化之后改开口说法.md](12-初始化之后改开口说法.md) | 补别人怎么叫它 | 「别人还可以说『提炼待办』」 |
| [06-初始化之后怎么打包.md](06-初始化之后怎么打包.md) | 规则改完了，打安装包 | 「升到 0.2.0，打一份安装包」 |
| [13-初始化之后发版检查没过.md](13-初始化之后发版检查没过.md) | 检查没过会停，先修再打包 | 「打一份安装包」 / 「发版检查一下」 |
| [14-初始化之后打错字.md](14-初始化之后打错字.md) | 错别字可直接改、不升版本 | 「说明里有个错别字，改一下」 |
| [15-初始化之后回滚.md](15-初始化之后回滚.md) | 这版不行就回到上一版 | 「这版不行，回到上一版」 |
| [16-初始化之后装到助手里试用.md](16-初始化之后装到助手里试用.md) | 你开口才拷进助手 | 「装到助手里试用」 |

助手一次只问一件事。已经说过的不会再问。初始化最后给你一张清单，说「按这个写」才动手。升级最后给你方案，说「同意执行」才改文件。
