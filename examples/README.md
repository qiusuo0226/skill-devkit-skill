# 使用示例

看怎么开口、助手问什么、你怎么回、文件夹里会多出什么。

人名和 Skill 名是假的，问法是真的。贯穿始终：林夏要做一个「会议速记」技能——把会议纪要收成决议和行动项。

```mermaid
flowchart LR
    A["空文件夹"] --> B["说：初始化 skill"]
    B --> C["问完、你点头"]
    C --> D["文件夹里有了这个技能"]
    D --> E["以后不必再打开本包"]
```

```mermaid
flowchart LR
    F["工作区换成那个技能的文件夹"] --> G["说要改什么"]
    G --> H["方案写到 governance/planning/upgrade-plan-v版本.md"]
    H --> I["可直接执行升级 或 另开对话 B 审"]
    I --> J["人同意后才改技能、打安装包"]
```

建议先看 01。写到一半再开口看 25。建好之后：写规则看 10，升级必看 08，人直接执行看 21，B 审核看 22，记缺口看 24。老技能没有规范看 17。

## 初始化之后

工作区换成**那个技能的文件夹**。不要再对本包说。改技能正文前先出七章方案。你可直接「执行升级」，或另开对话让 B 审后再同意。

| 文件 | 看什么 | 你开口可以这样说 |
|---|---|---|
| [08-初始化之后怎么升级.md](08-初始化之后怎么升级.md) | **必看。** 七章、路径、两条路 | 「升级这个 skill。给它加一个能力：……」 |
| [21-初始化之后A出方案人直接执行.md](21-初始化之后A出方案人直接执行.md) | 不经 B，人直接执行 | 「执行升级」 |
| [22-初始化之后B审核再执行.md](22-初始化之后B审核再执行.md) | B 只追加文末 | 「你是 Agent B，审核 upgrade-plan-vX.md」 |
| [23-同一对话从A转B会停.md](23-同一对话从A转B会停.md) | 不能自己审自己 | （请新开对话） |
| [24-初始化之后记升级需求.md](24-初始化之后记升级需求.md) | 做不到先落稿，不改正文 | 「这是 skill 的问题，记成升级需求」 |
| [09-对本包说升级会停.md](09-对本包说升级会停.md) | 对本包说升级写不出方案 | （先换文件夹） |
| [10-初始化之后写规则.md](10-初始化之后写规则.md) | 空架子写规则 = 第一轮升级 | 「把技能真正要做的规则写进去」 |
| [11-初始化之后直接改会先出方案.md](11-初始化之后直接改会先出方案.md) | 说「直接改吧」也先出方案 | 「技能正文加上：……」 |
| [12-初始化之后改开口说法.md](12-初始化之后改开口说法.md) | 补别人怎么叫它 | 「别人还可以说『提炼待办』」 |
| [06-初始化之后怎么打包.md](06-初始化之后怎么打包.md) | zip 叫什么、打在哪 | 「打一份安装包」 |
| [13-初始化之后发版检查没过.md](13-初始化之后发版检查没过.md) | 检查没过会停 | 「打一份安装包」 |
| [14-初始化之后打错字.md](14-初始化之后打错字.md) | 错别字可不升版本 | 「说明里有个错别字，改一下」 |
| [15-初始化之后回滚.md](15-初始化之后回滚.md) | 回滚对着上一版基线 | 「这版不行，回到上一版」 |
| [16-初始化之后装到助手里试用.md](16-初始化之后装到助手里试用.md) | 你开口才拷进助手 | 「装到助手里试用」 |

助手一次只问一件事。初始化说「按这个写」才动手。升级说「同意执行」或「执行升级」才改技能。
