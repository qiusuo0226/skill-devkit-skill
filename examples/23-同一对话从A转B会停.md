# 示例：同一对话从 A 转 B 会停

刚在这个对话里出过方案，不能接着说「你是 Agent B」。否则等于自己审自己。请新开对话，把方案路径交出去。

---

**你**

> （同一对话，方案刚写完）你是 Agent B，审核刚才那份方案。

**助手**

> 这份方案是本对话里写的，不能在这里转成审核。
>
> 请新开一个对话，说：「你是 Agent B，审核 governance/planning/upgrade-plan-v0.3.0.md」。
>
> 或者你自己看完七章，直接回复「执行升级」。

---

## 你可以照着说

新对话：

```text
你是 Agent B，审核 governance/planning/upgrade-plan-v0.3.0.md。
```
