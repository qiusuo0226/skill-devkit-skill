## 这版改了什么

- 审核升级方案时，用编辑工具把 `## B{N} 审核结果` 追加到方案文件末尾，然后回读。末尾没有这一节时，回复第一句是「没有写入」加上该路径。不要把审核节全文只写在对话里。
- 方案模板文末是这段明文，不再是 HTML 注释。写方案的人必须把这段留在文末。
- 对本包说「你是 Agent B」，并且点名的是本包已经存在的 `governance/planning/upgrade-plan-v*.md`：只追加并回读，不改种子，不执行升级。写方案、Agent A、执行升级、核对效果仍然停止。

## 使用者要做什么

- [x] 无需迁移工作区
- [ ] 要用这条：用新 zip / 新目录替换已安装的本包
- [ ] 已建好的技能仓**不会**自动改。要这条：在那个仓单独升级，或手抄本版 `assets/seed/upgrade-dual-agent.md` 的 B 步骤、`assets/seed/skill-governance.md` 路径 B 那一句，以及 `assets/templates/upgrade-plan.md` 的文末段落
- [ ] 新初始化、新收编会带上新种子

无。没有点名本仓已有方案时，对本包说「你是 Agent B」仍然停止。路径 H 仍可无人审核而执行。
