## 这版改了什么

- 写方案、审核、执行之前先对齐远程。各远程默认分支尖端必须是同一个提交。本地只是落后才快进。超前或分叉则停，不 merge、不 rebase、不 reset、不强推。没有远程则在快照里写明后继续。
- 多个 tag 推远程时，每个远程从旧到新逐个推。祖先提交上的 tag 先推。同一提交按语义化版本从旧到新。一个 tag 一条命令，上一个在该远程可见再推下一个。缺的 tag 轮到才创建。禁止先全部打好再一起推，禁止 `git push --tags`，禁止 `--follow-tags`，禁止一条命令多个 tag。已有本地 tag 不删、不改、不重打。没点名的 tag 不跟着推。
- zip 打包不变。没让推仍然不推。
